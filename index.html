Projects & Skills

Four things I have learned in this course, and where you can see them on this page.

Semantic HTML5

I structure a page with header, nav, main, section and footer, add alt text to images, and label every form field so the page makes sense to everyone, including screen reader users.

Responsive CSS

I style with external CSS, the box model, Flexbox and Grid, and a media query so the layout works on both phones and computers. The light and dark themes use CSS variables.

Interactive JavaScript

I use events and DOM updates to validate a form, flip through a photo gallery, switch themes and open a mobile menu.

GitHub and Render

I keep my code in a GitHub repository with clear commit messages, then publish it as a live static website on Render.
